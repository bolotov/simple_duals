## simple_duals
Studying duals and making a lib for auto-differentiation for places where
industry standard toolkits are not available and you need "something".
It was made not for competing with anyone for making things done instead.

For now it is more a playground than an actual library, we will see.

### The Industry Standard Autograd Toolkits

JAX (jax.grad): Google's package

Autograd: Differentiates native Python and NumPy code.

PyTorch (torch.func.grad): This machine learning framework has functional
gradient operators.

### Standalone or Educational Micro-Libraries

PyGrad A NumPy-based mini automatic differentiation library utilizing
a define-by-run approach similar to PyTorch.

MyGrad: A reverse-mode automatic differentiation with NumPy.
